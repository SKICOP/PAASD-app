# PAASD-app

Protótipo interativo do **PAASD – Plataforma de Atendimento e Acompanhamento de Saúde Domiciliar**, projeto acadêmico de empreendedorismo com piloto em Campo Mourão (PR).

O protótipo é um único arquivo, `index.html`. Abra no navegador para testar as telas Início, Agendar, Acompanhar e Família.

Todos os nomes, valores e dados clínicos são fictícios e servem apenas para demonstração.
